# ANYWEAR — Responsive Fashion Store Test

Static responsive demo built from the uploaded product image.

## Run
Open `index.html` in a browser.

## Included
- Responsive desktop/tablet/mobile layout
- Black / grey / white product variants
- Color swatches and image switching
- Size selection
- Demo add-to-bag interaction
- Sticky header
- Product details accordions
- Editorial brand sections
- No backend / no real checkout

Replace files in `assets/` with final product photography when ready.
